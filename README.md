# 📝 To-Do List App

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks:
  - All
  - Active
  - Completed
- Data persistence using Local Storage
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
